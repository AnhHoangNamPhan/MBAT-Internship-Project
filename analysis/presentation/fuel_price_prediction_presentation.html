Problem Statement

Challenge for Central European Travelers and Fuel Consumers

  • Volatile pricing: Prices fluctuate by location, time of day, and brand.
  • Fragmented data: Fuel prices are collected and published separately by each country.
  • Lack of predictive insight: Online sources show only current prices, no analytical benchmark.
  • Planning inefficiency: Drivers lack tools to estimate nearby prices.

Problem Statement

Research Motivation

“Transparency in fuel pricing benefits consumers by enabling informed decision-making and promoting market competition” - Springer Research on Fuel Price Transparency

2. Spatial Features

Large Dataset Strategies

Challenge: 36GB Dataset

Problem: Loading Large-scale data 36GB into R memory is insufficient

Solution: Streaming data chunks and Smart Sampling

Large Dataset Strategies

Streaming/Chunked Processing

  • Incremental Learning: Process data in 500K-record chunks
  • Memory Efficient: Never load full dataset
  • Real-time Updates: Model updates with new data

Large Dataset Strategies

Smart Sampling

  • Representative Samples: Stratified sampling by country and fuel type
  • Temporal Coverage: Maintains time series properties
  • Geographic Balance: Ensures spatial representation

Model Selection & Methodology

Linear Regression

  • Method: Incremental fitting with mini-batch gradient descent over DuckDB data.
  • Advantages: Interpretable, fast, scalable to millions of rows via chunking.
  • Use case: Baseline performance and feature interpretability. Supports incremental fitting.

Model Selection & Methodology

Machine Learning Models

  • Random Forest: Ensemble method for non-linear relationships
  • XGBoost: Gradient boosting for complex patterns
  • Neural Networks: Deep learning for high-dimensional features
